  set exactly. All records, available or not, join to the actual corpus,
  S1 records, source contracts and production CaseRun. Missing, extra,
  unselected, unknown and duplicate IDs fail even when the oracle's own

- **A2:** both context directions are checked against the joined source.
  Ordinary and Assert records retain required source and target evidence;
  unknown, duplicate and missing evidence fails. Target witness types must
  be compatible with an independent source-derived expected type.
- **A3:** available oracle targets require an actual successful Lean
  disposition, type, availability/trace evidence, no failure record, and a
  successful replay of the existing Lean checker in the actual source
  environment. Type/effect/trace fields must agree with that replay, and the
  type must be compatible with the independent expected type. A rejected
  outcome's retained AST is diagnostic data, not typed parity. Such failures
  are recorded as `typed-outcome` differences and fail the whole gate.

The new `M2_ORACLE_SOURCES.sexp` is generated by the existing frozen-A0
**source admission phase only** (`export_m2_redex_oracle.rkt --sources`).
It does not read the candidate oracle, call candidate-target expansion, or
consult Lean outcomes. The consumer therefore does not let two mutually
consistent but corrupted oracle type fields define their own expected type.
The normal generator gate checks these source contracts against current
inputs. This retains the trusted Redex producer boundary; it is not a third
general checker or a Lean re-proof of all Redex derivations.

Two representation adaptations are explicit: closed Assertion/Expressive
indices in Act/ActOccurrence positions, and the source joint-lambda parameter
vector versus the existing M1 decoder's nested unary lambdas. The latter is
guided by the actual source binder syntax, not by candidate output and not
by flattening arbitrary function-valued results. All type checks then use
the existing `Ty.compatible` relation, preserving genuine checking
refinements such as Natural at expected Number. No typing theorem or source
equation was weakened.
