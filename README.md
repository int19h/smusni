# smusni notation design

The authoritative version-0 design is:

- [spec.md](spec.md) — syntax, types, elaboration, semantics, canonicalization,
  fallback, and validation requirements;
- [samples.md](samples.md) — complete and explicitly labelled fragmentary
  specimens used to exercise the design.

Git history contains the superseded drafts and supporting design research; they
are not part of the live format contract.
